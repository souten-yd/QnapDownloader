# Rapidgator URL抽出（オフライン・手動操作）

v0.1.2の機能。サイトからコピーしたHTML/テキストを管理画面の入力欄に貼り付け、Rapidgator (`rapidgator.net`/`rg.to`) のHTTPSファイルリンク候補を抽出します。

サーバーから外部サイトへ一切アクセスしません。JavaScript、iframe、HTMLの埋め込みコンテンツを実行せず、Cloudflare等の保護を回避しません。meta refreshやscriptのURLは抽出対象に含めません。

1回の入力は64KiB以下。プレビューは既定最大20件、API上限100件。HTTPSの許可ドメインと /file/<識別子> だけを正規化し、クエリ/追跡パラメータを除いて重複排除します。抽出結果はDOMのtextContentで表示し、外部HTMLを直接レンダリングしません。

プレビューではリンクキューに書き込みません。利用者が「確認したリンクを保留キューに登録」を明示して押した時だけ、元入力のSHA-256がプレビュー時と一致していることを検査し、SQLiteの単一トランザクションでキューへ保存します。

保存したリンクは**JD2に自動送信されず、ダウンロードも開始しません**。JD2へ転送する場合は個別リンクの手動送信を明示します。JD2の実際の自動開始OFF、Dockerパスマッピング、Packagizerリスク許可などの既存ゲートはそのまま適用されます。

未実装: リモートWebページの取得、内蔵サンドボックスブラウザ、サイト自動クロール、Click'n'Loadの受信、パスワード付きファイルの自動処理。URLからファイルが実際にダウンロードできるかの検証はJD2側に委ねます。
