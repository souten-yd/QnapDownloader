       初期設定の進行状況
       
      
      
      
      
      メモリの保護: 空きメモリが2GiB未満、またはブラウザが上限(2GiB)の80%に達しているときはタブを開きません（他のアプリは止めません）。同時に開けるのは3枚までです。
      
      
      自動停止: タブが0枚のまま5分、または10分間操作がないと、コンテナごと停止してメモリを解放します（次回は数秒で再起動）。Webタブを閉じると、対応するNASブラウザのタブも閉じます。
      
      
      
      ONのとき、長押しでRapidgatorのリンクが見つかると確認なしでJD2へ送ります（送信済みのリンクは除外）。JD2へ送れない状態や送信に失敗したときは、従来どおりシートを開きます。
      
      
      
      既知の広告・トラッカー・ポップアンダー配信元（Hub内の固定リスト）への通信をChromiumで止め、表示を軽くします。Rapidgatorなどのホスターは止めません。サイトごとに下の一覧でOFFにできます。

      Tailscale ServeでHTTPSにする
      
      
      Hubは新しい待ち受けを増やさず、Tailscale ServeがHTTPS（ts.netの証明書）をNASの中で終端して、Hubへ転送します。
      
      
        
       
      1. Tailscale管理画面で MagicDNS と HTTPS証明書 を有効にします。
        2. 
       
      2. NASにSSHで入り、次のコマンドを実行します。
        
        tailscale serve --bg --https=443 http://127.0.0.1:17864
        
        QNAPのTailscaleアプリではコマンドの場所が異なることがあります。which tailscale で探すか、App Centerのインストール先（/share/CACHEDEV1_DATA/.qpkg/Tailscale/ など）を確認してください。
       
        3. 
       
      3. https://<NAS名>.<tailnet名>.ts.net/ を開き、ホーム画面に追加し直します。
        4. 
      
      
      
      HTTPSで開くと通過しやすくなります。Cloudflare確認は、HTTPS＋互換モード＋サイトが埋め込みを許可している場合に通過できる見込みです。iPhoneでは失敗することがあり、その場合は「iPhoneから送る」の共有メニュー方式（Safariで開いてリンクを送る）を使ってください。
      
     
      

     
      
      
      iPhoneから送る
      
      
      iPhoneの共有メニュー（ショートカット）からリンクを「追加したリンク」に送ります。JD2への送信やダウンロード開始は行いません。
      
      
      この画面はHTTPで開かれています。トークンが暗号化されずに送られるため、HTTPS（「HTTPS接続」参照）またはTailscale経由での利用をおすすめします。
      
      
      登録した端末
      
      
      
      
      
       
       
      
      
      
      
       
      トークン（この画面を離れると二度と表示されません。今すぐショートカットに貼り付けてください）
      
       
      
      
      
      
      エンドポイント
      
      
      
      
      ショートカットの作り方
      
      
        
       
      1. ショートカットApp → 新規 → 詳細で「共有シートに表示」をONにし、入力を「URL・テキスト・Safari Webページ」にします。
        2. 
       
      2. アクション「WebページでJavaScriptを実行」を追加し、次のコードを貼り付けます（Safariから共有したときだけ動きます。テキストを共有する場合はこのアクションを省きます）。
        
        
       
        3. 
       
      3. アクション「URLの内容を取得」を追加し、URLに上のエンドポイント、方法を POST、ヘッダに Authorization = Bearer <トークン> と Content-Type = application/json、本文はJSONで text = 前のアクションの結果 にします。
        4. 
       
      4. アクション「通知を表示」を追加し、結果を表示します。
        5. 
      
      
      
      エンドポイントはiPhoneから届く必要があります（Tailscale接続）。トークンを平文で送らないようHTTPSを推奨します。
      
      
      ブックマークレット（任意）
      
      
      Safariのブックマークとして登録すると、開いているページのURLを「リンク」の貼り付け欄に入れます（自動では保存しません）。

      このアプリについて
      
      
      QnapDownloader 
      
      
      JDownloader 2とWeb管理画面を組み合わせた、QNAP向けのダウンロード管理ツールです。
      
      
        
       
      • 初期開発版です。実機（TS-253Be）でのJD2の動作は未検証です。
        • 
       
      • 自動ダウンロードとサイトの自動巡回はありません。追加したリンクは手動でJD2へ送ります。
        • 
       
      • Rapidgatorのリンクは、貼り付けたテキストやHTMLから抽出できます。
        • 
       
      • Webの閲覧は端末側の隔離表示です。表示できないサイトはSafariで開いてください（「Safariで開く（次回から自動）」でサイトごとに記憶できます）。
        • 
       
      • 枠内で遷移した先のURLは読み取れません。サイトが埋め込みを禁止している場合は空白になります。
        • 
       
      • 互換モードでは、そのサイト自身のCookie・ストレージを枠内で使えます（Hub自体のものではありません）。
        • 
      
      
      
      
       詳細
       
      外部ページの取得はブラウザ側の隔離iframeだけで行い、NASは外部ページを取得しません。JD2とJavaはQPKGに同梱されず、公式の固定URLからSHA-256検証つきで導入します。JD2本体の更新はJD2の公式機能が行い、Hubの更新は影響しません。
