    送信の動作
    
       
    
        
    JD2へ送ったらすぐダウンロード開始

    ⓘ
    ONのとき、Hubから送ったリンクはJD2の待機に残らず、すぐダウンロードが始まります。JD2自体の自動確定・自動開始の設定は変更しません。
    
        
       
    
       
    
        
    長押しで見つかったリンクを自動でJD2へ送る
         NASブラウザの長押しで見つかったリンクを送ります
          
     ⓘ
    ONのとき、長押しでRapidgatorのリンクが見つかると確認なしでJD2へ送ります（送信済みのリンクは除外）。JD2へ送れない状態や送信に失敗したときは、従来どおりシートを開きます。
    
        
       
    
      
    
     
    

     
    
      
    ブラウザ
    
      
    
       
    NASブラウザ
    
       
    表示できないサイトをNAS上のChromiumで開きます
        
    ⓘ
    Cloudflareなどで手元のブラウザでは開けないサイトを、NAS上のコンテナ内ブラウザで開き、画面だけを受け取って操作します。外部サイトの通信やスクリプトは端末に届きません。ファイルのダウンロードは無効です。空きメモリが2GiB未満、またはブラウザが上限(2GiB)の80%に達しているときはタブを開きません。同時に開けるのは3枚までです。タブが0枚のまま5分、または10分間操作がないと、コンテナごと停止してメモリを解放します。
    
       
    
        
    確認しています…
    
        
    
         
         
         
        
    
       
    
       
    
        
    NASブラウザを常駐
         タブがなくても起動したままにして、開くのを速くします
          
    ⓘ
    オンにすると、Hubの起動時（と切り替えた直後）に、イメージがあり空きメモリが足りていればNASブラウザを起動し、タブが0枚でも止めません。タブを閉じるとChromiumにメモリの解放を依頼し、60秒後に待機時のメモリを測ります。予期せず停止したときは、5秒→15秒→60秒の間隔で自動的に再起動します（15分に5回まで。超えたら止めて「再試行」を出します）。再起動の前には毎回空きメモリを確認します。オフにすると、これまでどおりタブが0枚で5分後に停止します。

        Tailscale ServeでHTTPSにする手順
        
      Hubは新しい待ち受けを増やさず、Tailscale ServeがHTTPS（ts.netの証明書）をNASの中で終端して、Hubへ転送します。iPhoneの共有メニュー（ショートカット）から送るときのトークンも、HTTPSなら暗号化されます。
      
        
        
         
      1. Tailscale管理画面で MagicDNS と HTTPS証明書 を有効にします。
        2. 
         
      2. NASにSSHで入り、次のコマンドを実行します。
          
        tailscale serve --bg --https=443 http://127.0.0.1:17864
        
          QNAPのTailscaleアプリではコマンドの場所が異なることがあります。which tailscale で探すか、App Centerのインストール先（/share/CACHEDEV1_DATA/.qpkg/Tailscale/ など）を確認してください。
         
        3. 
         
      3. https://<NAS名>.<tailnet名>.ts.net/ を開き、ホーム画面に追加し直します。
        4. 
        
      
       
      
      
      

      
      
       
      iPhoneから送る
      
       
      共有メニューからリンクを「追加したリンク」へ送ります
        
      ⓘ
      iPhoneの共有メニュー（ショートカット）からリンクを「追加したリンク」に送ります。JD2への送信やダウンロード開始は行いません。エンドポイントはiPhoneから届く必要があります（Tailscale接続）。トークンを平文で送らないようHTTPSを推奨します。
      
       
      この画面はHTTPで開かれています。トークンが暗号化されずに送られるため、HTTPS（「HTTPS」参照）またはTailscale経由での利用をおすすめします。

        ショートカットの作り方・エンドポイント
        
      エンドポイント
      
        
      
        
        
         
      1. ショートカットApp → 新規 → 詳細で「共有シートに表示」をONにし、入力を「URL・テキスト・Safari Webページ」にします。
        2. 
         
      2. アクション「WebページでJavaScriptを実行」を追加し、次のコードを貼り付けます（Safariから共有したときだけ動きます。テキストを共有する場合はこのアクションを省きます）。
          
        
         
        3. 
         
      3. アクション「URLの内容を取得」を追加し、URLに上のエンドポイント、方法を POST、ヘッダに Authorization = Bearer <トークン> と Content-Type = application/json、本文はJSONで text = 前のアクションの結果 にします。
        4. 
         
      4. アクション「通知を表示」を追加し、結果を表示します。
        5.

      このアプリについて
      
       
      QnapDownloader 
      
       
      JDownloader 2とWeb管理画面を組み合わせたQNAP向けダウンロード管理ツール
      
       
      
        詳細
        
        
         
      • 初期開発版です。実機（TS-253Be）でのJD2の動作は未検証です。
        • 
         
      • 自動ダウンロードとサイトの自動巡回はありません。追加したリンクは手動でJD2へ送ります。
        • 
         
      • Webの閲覧はすべてNASブラウザ（Container Station上のChromium）で行います。端末側で外部ページを直接表示することはありません。
        • 
        
      
        
      外部ページはNASブラウザのコンテナだけが取得し、このHubの画面にはJPEGと検証済みのテキストだけが届きます。JD2とJavaはQPKGに同梱されず、公式の固定URLからSHA-256検証つきで導入します。
